# Accesibilidad Web: Auditoría, Resolución y Buenas Prácticas

> *"La Accesibilidad Web significa poner Internet y sus servicios a disposición de las personas, sean cuales sean sus requisitos de hardware o software, su infraestructura de red, su idioma materno, su contexto cultural, su ubicación geográfica o sus aptitudes mentales y físicas."* — Tim Berners-Lee

**Visión del Proyecto**
Este repositorio documenta mi proceso práctico, técnico y analítico dentro del programa de Accesibilidad Web de la Universidad Nacional de La Plata (UNLP). El objetivo de este espacio es demostrar que la accesibilidad debe integrarse desde el "kilómetro cero" del desarrollo. Un producto digital accesible no solo garantiza el derecho a la información, sino que expande de manera tangible el alcance del negocio, la retención de usuarios y la conversión en ventas.

**Stack de Auditoría y Testing**
*   **Lectores de Pantalla:** Testing de usabilidad con NVDA y VoiceOver.
*   *(En desarrollo: Próxima integración de herramientas de análisis automatizado y validación de código).*

**Enfoque QA Visual y Resolución de Problemas**
Mi metodología de control de calidad se basa en auditar el funcionamiento eficiente de los flujos web para garantizar una ejecución correspondiente. 
*   **Caso de Estudio (Unidad 2 - ANSES):** Ejecutando pruebas de interacción, audité el sistema de validación de identidad gubernamental. Detecté una barrera crítica: el reCAPTCHA de audio diseñado para personas ciegas se reproduce íntegramente en inglés, mientras que el usuario hispanohablante navega con VoiceOver en español. Este hallazgo documenta cómo una mala implementación técnica bloquea por completo la autonomía del usuario.

**Estructura del Repositorio**
*   **Auditorías y Resoluciones:** Análisis de usabilidad, reporte de inconsistencias y resolución de actividades prácticas con enfoque de Quality Assurance (QA).
*   **Validación de Conocimientos:** Exámenes y pruebas técnicas de cada unidad.
*   **Base Documental:** Documentación técnica, normativas y textos de estudio (PDFs) analizados durante el programa.
